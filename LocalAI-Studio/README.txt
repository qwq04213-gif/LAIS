로컬 AI 스튜디오  -  대화 + 고품질 이미지 편집/생성 통합 패키지
=====================================================================

내 PC 안에서만 동작합니다(최초 설치·모델 다운로드 때만 인터넷 사용).
브라우저 화면에서 기능을 골라 쓰고, 필요한 모델도 그 화면에서 골라 설치합니다.


[필요한 환경]
  - Windows 10/11 64bit
  - NVIDIA GPU  (VRAM 8GB 이상, 12GB 이상 권장)  /  RAM 16GB 이상 (Qwen 편집은 32GB 이상 권장)
  - 여유 디스크: 엔진 약 12GB(설치 중 임시로 5GB 더 필요) + 모델 (대화 6~20GB, 이미지 편집 약 40GB)


[설치 방법]
  1. 이 폴더를 영문 경로에 풀어 주세요.            예) C:\LocalAI
  2. install.bat 더블클릭                          (ComfyUI 포터블 + Ollama 설치, 약 5GB 다운로드)
  3. start.bat 더블클릭                            (브라우저에서 http://127.0.0.1:7860 이 열립니다)
  4. [설치와 모델] 탭 -> "내 GPU에 맞춰 고르기" -> "선택한 항목 설치"
  5. 다운로드가 끝나면 원하는 기능을 바로 사용

  종료: start.bat 창을 닫으면 모든 엔진이 함께 종료됩니다.


[업데이트하는 방법]   (엔진·모델을 다시 받지 않아요)
  1. 받은 LocalAI-Studio-update-버전.bat 파일을 설치 폴더(start.bat 이 있는 폴더)에 넣어요.
  2. 스튜디오(start.bat 창)를 닫고 그 파일을 더블클릭해요. 몇 초면 끝나요.
  3. start.bat 으로 다시 실행하고, 브라우저에서 Ctrl+F5 로 새로고침해요. 현재 버전은 왼쪽 위 제목 아래에 나와요.
  - 바뀌는 것: 앱 파일(hub\, scripts\, README 등)뿐이에요. engine\, models\, outputs\, logs\ 와 브라우저에 저장된
    설정·프리셋·대화는 그대로예요.
  - 안전장치: 바꾸기 전에 backup\날짜_이전버전\ 에 이전 파일을 보관하고(최근 5개), 오류가 나면 자동으로 되돌려요.
    같은 파일은 건너뛰어서 여러 번 실행해도 안전해요. 스튜디오가 실행 중이면 멈춰요.
  - 직접 고친 설정 파일: profiles.json / models.json 은 덮어쓰지 않고 새 항목만 합쳐요(새 버전 전체는 이름.new 로 저장).
    wildcards 파일을 고쳤다면 그대로 두고 .new 만 만들어요.
  - 마음에 안 들면 rollback.bat 으로 직전 상태로 되돌릴 수 있어요(되돌릴 수 있는 목록: rollback.bat --list).
  - 확인만 하고 싶으면 명령 프롬프트에서 LocalAI-Studio-update-버전.bat --dry-run (아무것도 바꾸지 않고 바뀔 파일만 보여 줘요).
  - 업데이트 파일이 '찾을 수 없음'이라고 하면 설치 폴더에 넣었는지 확인하세요. 윈도 보안 경고가 뜨면 파일 속성의
    '차단 해제'를 체크하거나 '추가 정보 > 실행'을 누르세요. 그래도 막히면 같이 받은 LocalAI-Studio.zip 의 내용을
    설치 폴더에 덮어 풀어도 같은 효과예요(이 경우 직접 고친 profiles.json, models.json 은 덮어써지니 미리 복사해 두세요).


[화면별 기능]
  대화          Ollama 기반 로컬 LLM. 무검열(abliterated)/롤플레이 특화 모델 선택, 역할 지침, 창의성·기억 길이,
                Top-P/Top-K/Min-P/반복 억제/최대 길이/시드/중단 문자열. 대화는 브라우저에만 저장됩니다.
  이미지 편집   (원본과 결과가 나란히 표시돼요. 결과 칸의 [겹쳐서 비교]로 슬라이더 비교, [이어서 편집]으로 결과를 다시 원본으로)
                - 말로 편집 (Qwen-Image-Edit 2509): "재킷을 붉은 가죽으로 바꿔줘". 참조 이미지 최대 2장,
                  칠한 영역만 바꾸고 나머지는 원본 픽셀 그대로 유지, '원본 해상도로 복원', 빠른 모드(Lightning).
                - 칠해서 편집 (SDXL 인페인트): 칠한 영역 주변만 잘라 모델 해상도로 다시 그린 뒤 부드러운 경계로 합성.
                  처리 해상도·주변 포함 범위·경계 부드러움·변화 강도 조절, 체크포인트/LoRA/프로필 사용 가능.
  이미지 생성   '모델 종류'에서 고릅니다.
                - SD1.5 / SDXL / Illustrious / Pony / NoobAI: 체크포인트 방식. 하이레스 픽스(2단계), 이미지->이미지,
                  ControlNet(포즈/캐니/깊이), V-Prediction, CFG 재조정, PAG, VAE 선택, 샘플러·스케줄러.
                - FLUX.1 / Krea: 문장형 프롬프트, 가이던스. Chroma: 무검열 FLUX 계열, 네거티브 프롬프트와 CFG 사용.
                  [설치와 모델]에서 설치하면 모델 목록에 나와요(공용 텍스트 인코더·VAE 는 자동으로 같이 설치).
                  직접 받은 FLUX 계열 파일은 diffusion_models 폴더에 넣어요(Chroma 는 파일 이름에 chroma 가 있어야
                  Chroma 목록에 나와요). 이미지->이미지, LoRA, 다이나믹 프롬프트는 FLUX 계열에서도 쓰고, 하이레스 픽스·ControlNet·PAG 는 SDXL 계열 전용이에요.
                - LoRA 는 [+ LoRA 추가]로 개수 제한 없이 쓸 수 있어요(VRAM 이 허락하는 만큼).
  업스케일      Real-ESRGAN 2배/4배, 또는 '디테일 재생성'(업스케일 후 겹치는 타일로 낮은 변화 강도 재생성).
  이미지 정보   PNG/JPEG/WebP 의 프롬프트·생성 설정(ComfyUI, A1111/Forge, NovelAI, InvokeAI), 캐릭터 카드(PNG),
                EXIF(촬영 위치 GPS 경고 포함)를 읽습니다. 생성 탭/워크플로 탭/대화로 바로 보내거나,
                메타데이터를 화질 손실 없이 지운 사본을 저장할 수 있습니다.
  워크플로      ComfyUI 에서 'Save (API Format)'으로 저장한 워크플로를 그대로 실행합니다(프롬프트·시드·크기·입력 이미지 수정).
                ComfyUI 에서 할 수 있는 거의 모든 것을 쓸 수 있는 통로입니다. ComfyUI 고급 화면도 왼쪽 아래 링크로 열려요.
  설치와 모델   GPU 맞춤 추천, 대화/이미지 모델 설치, Civitai·HuggingFace 주소로 직접 추가(체크포인트·LoRA·임베딩 등).
  공통          [중단] 버튼: 생성·편집·업스케일·워크플로 작업을 실행 중에 멈춰요(여러 장 중 끝난 것은 남겨요).
                진행 상태는 이미지 바로 아래에 표시돼요. 설정 칸과 결과 칸 사이 세로 줄을 끌어서 너비를 조절해요(더블클릭=기본값).
                설정 이름 옆 ? 에 마우스를 올리면 쉬운 설명이 나와요. 모든 버튼은 눌림 효과가 있어요.
                [폴더 열기] 버튼(설치와 모델 탭, LoRA·FLUX·업스케일 설정 옆)으로 체크포인트·LoRA 등 폴더를 바로 열어요.
                폴더에 모델 파일을 넣고 이 창으로 돌아오면 목록이 자동으로 새로고침돼요.
                결과 이미지를 누르면 확대 뷰어(휠 줌, 드래그 이동, 더블클릭 100%, 방향키로 넘기기, 전후 비교).
                설정은 자동 저장되고, '내 프리셋'으로 이름 붙여 저장할 수 있습니다.
                결과 PNG 에는 프롬프트·설정이 기록되어(끌 수 있음) A1111/ComfyUI 에서도 읽을 수 있습니다.
                대화 <-> 이미지 기능을 오갈 때 상대 엔진의 VRAM 을 자동으로 비웁니다.
                결과 이미지는 outputs 폴더(왼쪽 아래 '결과 폴더 열기')에 PNG 로 저장됩니다.


[품질을 높이는 방법 - 성인 이미지 포함]
  1. 모델이 결과의 대부분을 정합니다.
     - 일러스트/애니: NoobAI-XL, Illustrious 계열(태그 프롬프트). 이름에 vpred 가 있으면 V-Pred 프로필이 자동 적용됩니다.
     - 사실적: Civitai 에서 NSFW 표시를 켜고 'SDXL' 사진 계열 체크포인트를 인기순/최신순으로 찾아
       [설치와 모델] > 직접 추가에 다운로드 주소와 API 키를 넣으세요. (모델 생태계는 빨리 바뀌니 직접 찾아보는 편이 좋아요.)
     - 사실적: FLUX.1 Krea(사진 질감, 성인 표현은 약함)와 Chroma(무검열, 성인 표현 제한 없음)를 [이미지 생성]의 모델 종류에서 쓸 수 있어요.
     - 그 밖의 최신 모델(영상, SD3 등)은 ComfyUI 화면의 템플릿 워크플로를 API 형식으로 저장해 [워크플로] 탭에서 실행하세요.
  2. 프로필: 체크포인트 이름을 보고 품질 태그, 기본 제외 요소, 샘플러, CFG, CLIP skip 을 자동으로 맞춥니다(hub\profiles.json 수정 가능).
  3. LoRA 는 포즈·의상·디테일·캐릭터를 조합하세요(각 0.5~0.9, 많이 겹칠수록 낮추세요). Civitai 예시 프롬프트의 <lora:이름:0.8> 태그는 그대로 붙여 넣으면 인식합니다.
  4. 하이레스 픽스(배율 1.5, 변화 강도 0.45~0.55)와 PAG(3)는 손·해부학 안정에 효과가 큽니다.
  5. 손·얼굴 등 망가진 부분은 [이미지 편집] 칠해서 편집으로 변화 강도 0.35~0.5, 처리 해상도 1024 로 부분 재생성하세요.
  6. 구도·포즈는 ControlNet(포즈 지도 또는 캐니 전처리)으로 고정하고, 마무리는 업스케일 > 디테일 재생성(변화 강도 0.25~0.35).
  7. 프롬프트: NoobAI/Pony 는 태그(1girl, red jacket), 사실적 SDXL 은 문장. (단어:1.2) 강조, {a|b} 무작위, __이름__ 와일드카드
     (wildcards 폴더의 이름.txt, 한 줄에 하나). 성인 캐릭터는 adult, mature female 처럼 연령을 분명히 적으세요.
  8. 대화(롤플레이): 롤플레이 특화 모델(Mag-Mell, Cydonia 등)+캐릭터 카드, 창의성 0.8~1.0, Min-P 0.05, 반복 억제 1.05~1.1.
  - Qwen-Image-Edit 는 범용 편집 모델이라 노출 표현 자체는 SDXL 계열보다 약합니다. 대신 인물/질감 일관성이 높아
    의상·배경·조명 변경이나 참조 이미지 합성에 강합니다.

[문제 해결]
  - 이미지 엔진 표시등이 꺼져 있음: 첫 실행은 1~2분 걸립니다. 계속 꺼져 있으면 logs\comfyui.log 확인.
  - "노드를 찾을 수 없음 / Qwen·PAG 오류": ComfyUI 가 오래된 경우입니다.
    engine\ComfyUI_windows_portable\update\update_comfyui.bat 실행 후 다시 시작하세요.
  - 메모리 부족(OOM): [빠른 모드] 사용, 더 작은 이미지/처리 해상도, 다른 프로그램의 GPU 사용 종료.
  - 회색/검은 이미지(NaN): 샘플링 설정에서 'SDXL VAE fp16 fix' 를 VAE 로 선택하세요.
  - FLUX/Chroma 가 '모델 없음'으로 나옴: 모델 파일이 diffusion_models 폴더에 있는지, 공용 파일(텍스트 인코더 t5xxl·clip_l, VAE ae)이
    설치됐는지 확인하세요. [설치와 모델]에서 FLUX 모델을 고르면 공용 파일도 같이 설치돼요.
  - 업데이트 후 화면이 그대로임: 브라우저에서 Ctrl+F5. 그래도 같으면 start.bat 창을 닫고 다시 실행하세요.
  - 다운로드가 404/실패: 모델 주소가 바뀐 경우입니다. hub\models.json 의 url 을 고치거나
    [직접 추가]에 새 주소를 넣으세요. 중단된 다운로드는 다시 설치하면 이어받습니다.
  - 대화 모델 이름이 틀려 설치 실패: [직접 추가]의 Ollama 모델 이름 칸에 올바른 이름(또는 hf.co/...)을 입력하세요.

[사용 원칙]
  - 성인이 자기 PC에서 쓰는 도구입니다. 성인 콘텐츠를 제한하는 필터는 없습니다.
  - 실존 인물의 사진은 본인 동의가 있을 때만 편집하세요. 동의 없는 노출·성적 합성물의 제작·유포는 불법입니다.
  - 미성년자와 관련된 성적 콘텐츠는 만들 수 없습니다. 프롬프트에 미성년 표현과 성적 표현이 함께 있으면

  - 다듬음: 작은 글씨(11px)를 12px 로 키우고, 밝은 테마에서 연하게 보이던 안내·상태 글자 색을 더 진하게 했어요. 일부 카드의 긴 이름이 잘리지 않고 줄바꿈돼요.
  - 이번 고침은 내 PC에서 직접 돌려 본 확인이 아직 없어요(가짜 엔진으로 동작만 확인했어요). 특히 노드 원인 확인은 실제 이미지 엔진 기록 형식에 따라 원인 줄이 비어 보일 수 있어요.

[2.2] 영상 소리·자막, 갤러리·보관함·점검 도구
  - 새로 생김: 사이드바 도구 > [영상 소리·자막]. 만든 영상(또는 내 컴퓨터의 영상)에 음성·음악을 입히고 자막을 넣어 새 영상 파일로 저장해요. 원본은 그대로예요. 소리는 [음성 만들기]·[음악 만들기] 결과나 내 파일(wav·mp3·m4a·ogg·flac)을 고르고, 크기·시작 위치를 정할 수 있어요. 영상과 소리 길이가 다르면 [영상 길이에 맞춤](소리가 길면 끝을 서서히 줄이며 자르고, 짧으면 뒤는 조용해요) 또는 [소리 길이에 맞춤](영상이 짧으면 마지막 장면에서 멈춰 있어요)을 골라요. 영상에 원래 소리가 있으면 없애거나 새 소리와 같이 들리게 할 수 있어요.
  - 자막: 줄마다 한 칸이에요. 시간을 적지 않으면 소리 길이(소리가 없으면 영상 길이)에 맞춰 글자 수대로 나눠 넣고, '0:01 ~ 0:04 문장'처럼 적거나 .srt 파일을 불러오면 그 시간대로 넣어요. 음성 만들기 결과를 고르면 그때 쓴 글이 자막 칸에 자동으로 들어가요. 글자 크기·위치·색·테두리·반투명 배경을 고를 수 있고, 자막 파일(.srt)도 같이 저장할 수 있어요. 영상 결과 아래 [소리·자막 넣기], 음성·음악 결과 아래 [영상에 넣기], 갤러리 영상의 ♪ 버튼으로도 열려요.
  - 영상을 합치는 데는 ffmpeg 가 필요해요. 없으면 첫 실행 때 [빠진 부품 설치(imageio-ffmpeg)] 버튼이 나와요. 그래픽카드·ComfyUI 는 쓰지 않고, 결과는 기록 갤러리의 [영상]에 쌓여요. 파일 올리기는 500MB 까지, 영상은 30분 이하예요(올린 파일은 사흘 뒤 자동 정리돼요).
  - 새로 생김: 기록 갤러리의 [정렬](최신순·오래된 순·파일 이름순)과 [같은 프롬프트끼리 모아 보기]. 대소문자·공백 차이는 같은 프롬프트로 보고, 그림 정보가 없는 파일은 맨 뒤 묶음에 모여요. 미리보기를 끈 상태에서도 쓸 수 있어요.
  - 새로 생김: 캐릭터·스타일 보관함의 [정렬](저장한 순·이름순·최근 사용순)과 [복제] 버튼. 복제하면 설정과 참고 이미지가 새 항목으로 복사돼요(이름 뒤에 '(복사)'). '이미지 생성에 넣기' 등으로 쓴 항목은 최근 사용순에서 앞으로 와요.
  - 새로 생김: [내 PC 점검]의 [자동으로 고칠 수 있는 것 전부 고치기]. 꼭 필요한데 빠진 항목 중 설치로 해결되는 것(확장·파이썬 부품·얼굴 교체 모델)을 순서대로 고치고, 이미지 엔진 다시 시작은 맨 마지막에 한 번만 안내해요. 선택 항목은 건드리지 않고, 아무것도 지우지 않아요.
  - 개선: 확장이 설치돼 있는데 노드가 안 보일 때의 [원인 확인]이 ReActor 처럼 자기 설치 단계(부품·모델 받기)가 있는 확장에도 쓰여요. 이 경우 [설치 단계 다시 하기]로 확인해 둔 설치 스크립트를 다시 돌려요.
  - 개선: [진단 파일 저장](설치와 모델 > 내 PC 점검 옆)이 [내 PC 점검] 결과와 ffmpeg·내장 파이썬 패키지 목록까지 함께 담아요. 프롬프트·이미지·API 키는 그대로 들어가지 않고, 사용자 이름과 설치 폴더 경로는 가려요.
  - 이번에 새로 만든 기능들은 내 PC에서 직접 돌려 본 확인이 아직 없어요(영상 합치기는 실제 영상 파일과 ffmpeg 로 확인했지만, 부품 설치 버튼·그래픽 환경은 확인하지 못했어요).

[2.3] 업스케일 배율 직접 입력·줄이기, FLUX·Krea 2 모델 지원
  - 바뀜: [업스케일]과 [일괄 처리 > 업스케일]의 배율이 2배/4배 고르기에서 숫자 입력으로 바뀌었어요(0.1 ~ 8, 소수 가능: 1.5, 2.5 …). 옆의 [0.5배 · 1.5배 · 2배 · 3배 · 4배] 버튼으로 바로 채울 수도 있어요. 업스케일 모델이 4배용이어도 원하는 크기에 맞춰 줄이거나 늘려서 정확한 배율로 저장해요. 결과 긴 변은 8192px 까지예요.
  - 새로 생김: 줄이기. 배율을 1보다 작게(예: 0.5 = 가로세로 절반) 적으면 업스케일 모델이나 이미지 엔진 없이 바로 줄여서 저장해요. 일괄 처리에서는 파일 이름이 '_축소x0.5' 로 붙어요(키울 때는 '_업스케일x1.5').
  - 새로 생김: [기능 모음 > 얼굴·손 자동 보정]을 FLUX.1 · Krea · Krea 2 · Chroma 모델로도 쓸 수 있어요. 모델 칸에서 그 모델을 고르면 단계 수·CFG 를 모델에 맞게 자동으로 정하고(예: Krea 2 Turbo 는 8단계), 얼굴 → 손 순서로 그 모델이 다시 그려요. 감지 모델과 확장(Impact Pack)은 그대로 필요해요.
  - 새로 생김: [기능 모음 > 참고 이미지로 그리기 — 스타일·얼굴 유지]를 FLUX.1 · Krea 2 모델로도 쓸 수 있어요(SDXL 의 IP-Adapter 확장은 이때 필요 없어요). 모델 종류마다 방법이 달라요.
      · Krea 2: 공식 '스타일 참조' LoRA 를 써요. '설치와 모델'에서 [Krea 2 스타일 참조 LoRA]를 설치해요.
      · FLUX.1 (Krea dev 포함): Redux 로 참고 이미지의 분위기·구성을 따라요. '설치와 모델'에서 [FLUX.1 Redux]를 설치해요(Redux 파일은 HuggingFace 에서 사용 동의 후 API 키가 있어야 받을 수 있고, 비상업 라이선스예요). 설치 뒤 이미지 엔진을 다시 시작해 주세요.
      · FLUX Kontext 모델: 참고 이미지를 조건으로 걸고 빈 화면에서 새로 그려서, 사람 얼굴·옷·물건이 그대로 이어지기 쉬워요. 얼굴을 따라 하려면 이 방법이 가장 잘 맞아요. 별도 설치물은 없어요.
      · Chroma: 참고 이미지 방식이 없어 모델 목록에서 뺐어요.
  - 이번에 새로 만든 FLUX·Krea 2 연결은 내 PC에서 직접 돌려 본 확인이 아직 없어요(가짜 이미지 엔진으로 연결 구성만 확인했어요). 모델이나 ComfyUI 버전에 따라 결과 품질이 다를 수 있어요.

[2.4] 사이드바 정리·설정형 화면·받기 취소
  - 바뀜: [기능 모음] 탭이 없어졌어요. 이미지 확장·영역별 프롬프트·설정 비교표·크기 자르기 회전·밝기 색 보정·얼굴 손 보정·참고 이미지로 그리기·얼굴 교체가 사이드바 [기타 기능] 아래에 하나씩 있어요(눌러서 접고 펼 수 있고, 펼친 상태를 기억해요).
  - 바뀜: [설치와 모델] · [프롬프트] · [다운로드] · [변경사항] 화면이 설정처럼 왼쪽 메뉴에서 카드를 하나씩 고르는 모양이 됐어요. 마지막에 보던 카드를 기억해요.
  - 새로 생김: 모델 받기 [취소]. 받는 중이거나 기다리는 항목을 취소하면 받던 임시 파일(.part)도 함께 지워요. 이미 설치된 모델은 건드리지 않아요.
  - 새로 생김: [추천 모델]에서 지금 고른 설치 항목과 대략의 용량을 보여줘요.
  - 바뀜: 화면 배율의 기본값이 이전의 125%와 같은 크기이고, 이름은 [보통 100%]로 바뀌었어요(기존에 고른 배율은 가장 가까운 항목으로 이어져요).
  - 바뀜: 작업 대기열 위치 선택이 [사이드바에 고정 / 왼쪽 / 오른쪽 / 직접 선택]이 됐어요. 예전 [생성 버튼 아래] 선택은 [사이드바에 고정]으로 바뀌어요.
  - 바뀜: 작업이 끝났을 때 나오는 알림에서 '(누르면 이동)' 글자를 뺐어요. 누르면 해당 화면으로 가는 동작은 그대로예요.
  - 고침: 다른 탭에 갔다가 [참고 이미지로 그리기]로 돌아오면 모델 목록의 FLUX·Krea 2 묶음이 사라지던 문제, 기능을 바꿀 때 이전 기능의 입력값이 따라와 엉뚱한 기능이 실행될 수 있던 문제, 갤러리 작은 칸에서 버튼줄이 칸 밖으로 넘치던 문제.
  - 정리: 툴팁·설명에 남은 '미검증' 문구와 옛 이름([기능 모음])을 정리했어요.
  - 개선: 이미지 엔진을 켤 때 시작 옵션 확인 결과를 저장해 두 번째 시작부터는 이 확인을 건너뛰어요. 시작이 끝나기까지 걸린 시간을 시작 창에 '[시작 시간]'으로 남기고, 엔진이 뜨자마자 기능 목록을 미리 읽어 첫 작업을 더 빨리 시작해요.
  - 새 화면 구성과 받기 취소, 엔진 시작 시간 단축은 가짜 이미지 엔진과 브라우저 시험으로만 확인했고, 내 PC에서 직접 돌려 본 확인은 아직 없어요.

[2.5] 뒤로가기·단축키, 미리보기 캐시, 가볍게 만들기
  - 새로 생김: 마우스 옆면 4번(뒤로)·5번(앞으로) 버튼과 Alt+←/→ 로 직전에 보던 화면으로 가요. 확대 보기나 작업 대기열이 열려 있으면 그것부터 닫아요. [설정 > 단축키]에서 끌 수 있어요.
  - 새로 생김: Alt+1~9 로 대화·이미지 생성·이미지 편집·업스케일·갤러리·프롬프트·설치와 모델·설정·시작하기로 바로 가고, ? 키로 단축키 목록을 열어요(글 쓰는 칸에서는 동작하지 않아요).
  - 고침: 다른 탭에 갔다 오면 고른 모델(체크포인트)이 맨 위 항목으로 바뀌던 문제. [기타 기능]은 기능마다 마지막에 고른 값과 올린 이미지를 따로 기억해요(동의 확인 칸은 기억하지 않아요).
  - 바뀜: 갤러리 미리보기는 처음 볼 때만 만들고, 사진을 지우면 그 미리보기도 같이 지워요. 용량이 상한(기본 500MB, [설정 > 메모리와 속도]에서 200MB~2GB)을 넘으면 오래 안 본 것부터 지워요. 원래 사진은 건드리지 않아요. 지워진 사진의 미리보기와 옛 방식 파일은 프로그램을 켤 때 정리해요.
  - 바뀜: 갤러리에서 화면 밖 칸은 그리지 않고, 영상은 화면 가까이 올 때만 불러와요.
  - 바뀜: 대기열에서 방금 돌린 것과 같은 모델을 쓰는 작업이 바로 뒤쪽(앞 6개 안)에 있으면 먼저 해서 모델을 다시 불러오는 시간을 아껴요. 직접 [위로/맨 위로] 옮긴 작업은 건너뛰지 않고, 한 작업이 두 번보다 더 밀리지 않아요. 먼저 한 작업에는 '같은 모델이라 먼저 해요'가 보여요.
  - 새로 생김: [설정 > 메모리와 속도]의 [이미지 모델을 메모리에 두는 시간](기본 30분). 이미지 작업이 없는 채로 그 시간이 지나면 이미지 모델을 그래픽 메모리에서 내려요. 번역할 때도 그래픽 메모리가 넉넉하면 이미지 모델을 내리지 않아서 다음 그림이 더 빨리 시작해요.
  - 개선: 대기열·상태 확인 간격을 작업 중엔 2초대, 쉴 때는 5~6초, 탭이 가려졌을 때는 더 길게 했고, 엔진이 켜져 있는지 확인한 결과를 2초 동안 기억해요. 음성 만들기·선택 도구의 목록은 시작할 때가 아니라 그 화면을 처음 열 때 불러와요.
  - 개선: 프로그램을 켤 때 이미지 엔진을 가장 먼저 켜고 나머지 준비를 같이 해요. 오래된 임시 파일 정리는 엔진을 켠 뒤로 미뤘어요.
  - 정리: 화면 코드를 hub\web\js 의 기능별 파일로 나눴어요(브라우저에는 하나로 이어 보내서 동작은 같아요). 쓰지 않는 스타일과 겹치던 안내 문구를 정리했어요. 업데이트 뒤 hub\web\app.js 가 남아 있어도 쓰이지 않아요.
  - 이번 내용은 가짜 이미지 엔진과 브라우저 시험으로만 확인했고, 내 PC에서 직접 돌려 본 확인은 아직 없어요(마우스 옆 버튼 동작, 같은 모델 묶기의 실제 시간 절약, 엔진 시작 시간 변화).

[2.5.1] 탭 반응 속도 개선
