ComfyUI 길잡이

ComfyUI를 처음 쓰는 분을 위한 용어 풀이와, 이 프로그램에서 어디서 쓸 수 있는지 정리한 표예요.

자주 나오는 말

체크포인트 (Checkpoint)
그림을 그리는 '화가' 본체 파일이에요. 이 파일에 따라 그림체가 크게 달라져요. 이미지 생성 → 체크포인트
LoRA
화가에게 특정 캐릭터·화풍·옷을 가르치는 작은 추가 파일이에요. 여러 개를 겹쳐 쓸 수 있어요. 체크포인트와 같은 계열만 맞아요.
VAE
그림을 최종 이미지로 풀어 주는 '현상기'예요. 색이 탁하면 VAE를 바꿔 보세요.
텍스트 인코더 (CLIP / T5)
프롬프트 글을 모델이 알아듣는 숫자로 바꿔 줘요. FLUX·Qwen 같은 최신 모델은 별도 파일이 필요해요.
프롬프트 / 제외 프롬프트
그리고 싶은 것 / 그리지 말았으면 하는 것을 적어요.
시드 (Seed)
무작위 출발점이에요. 같은 시드와 설정이면 같은 그림이 나와요. -1은 매번 새로 뽑기.
샘플러 · 스케줄러 · 단계 수
노이즈에서 그림을 꺼내는 방식·속도 배분·횟수예요. 모델 추천값(프로필)을 쓰면 안전해요. 기능 모음 → 설정 비교표로 직접 비교해 보세요.
CFG
프롬프트를 얼마나 엄격히 따를지예요. 너무 높으면 색이 진하고 부자연스러워져요.
변화 강도 (Denoise)
기존 이미지를 얼마나 새로 그릴지예요. 낮으면 원본 유지, 높으면 많이 바뀜.
인페인트 / 아웃페인트
칠한 영역만 다시 그리기 / 이미지 바깥으로 넓히기. 이미지 편집, 기능 모음 → 이미지 확장
ControlNet
포즈·윤곽선·깊이를 따라 그리게 해서 구도를 고정해요.
업스케일
해상도를 키우면서 디테일을 살려요. 업스케일 탭
노드 / 워크플로
ComfyUI의 '부품'과 '연결도'예요. 이 프로그램은 자주 쓰는 연결도를 대신 만들어 주고, 직접 만든 것은 워크플로 탭에서 실행할 수 있어요.

이 도구는 성인이 자기 컴퓨터에서 쓰도록 만들어졌고, 성인 콘텐츠를 제한하는 필터를 두지 않아요. 아래 내용에 동의해야 시작할 수 있어요.

  • 저는 성인이며, 만들거나 편집하는 인물은 모두 성인이거나 성인으로 설정한 가상의 인물이에요.
  • 실존 인물의 사진은 본인의 동의가 있을 때만 편집해요. 동의 없는 노출·성적 합성물을 만들거나 퍼뜨리는 일은 불법이에요.
  • 미성년자와 관련된 성적 콘텐츠는 만들지 않아요. 이런 요청은 자동으로 차단돼요.
