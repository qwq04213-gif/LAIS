사진을 여기로 끌어다 놓거나 · 기록 갤러리에서 골라 [LoRA 학습 사진으로]를 눌러도 돼요. 얼굴·대상이 잘 보이는 다양한 각도·배경·옷의 사진이 좋아요.

이미지를 끌어다 놓거나 클릭해서 고르세요. Ctrl+V로 붙여넣을 수도 있어요.

ComfyUI 길잡이

ComfyUI를 처음 쓰는 분을 위한 용어 풀이와, 이 프로그램에서 어디서 쓸 수 있는지 정리한 표예요.

자주 나오는 말

체크포인트 (Checkpoint)
그림을 그리는 '화가' 본체 파일이에요. 이 파일에 따라 그림체가 크게 달라져요. 이미지 생성 → 체크포인트
LoRA
화가에게 특정 캐릭터·화풍·옷을 가르치는 작은 추가 파일이에요. 여러 개를 겹쳐 쓸 수 있어요. 체크포인트와 같은 계열만 맞아요.
VAE
그림을 최종 이미지로 풀어 주는 '현상기'예요. 색이 탁하면 VAE를 바꿔 보세요.
텍스트 인코더 (CLIP / T5)
프롬프트 글을 모델이 알아듣는 숫자로 바꿔 줘요. FLUX·Qwen 같은 최신 모델은 별도 파일이 필요해요.
프롬프트 / 제외 프롬프트
그리고 싶은 것 / 그리지 말았으면 하는 것을 적어요.
시드 (Seed)
무작위 출발점이에요. 같은 시드와 설정이면 같은 그림이 나와요. -1은 매번 새로 뽑기.
샘플러 · 스케줄러 · 단계 수
노이즈에서 그림을 꺼내는 방식·속도 배분·횟수예요. 모델 추천값(프로필)을 쓰면 안전해요. 기타 기능 → 설정 비교표로 직접 비교해 보세요.
CFG
프롬프트를 얼마나 엄격히 따를지예요. 너무 높으면 색이 진하고 부자연스러워져요.
변화 강도 (Denoise)
기존 이미지를 얼마나 새로 그릴지예요. 낮으면 원본 유지, 높으면 많이 바뀜.
인페인트 / 아웃페인트
칠한 영역만 다시 그리기 / 이미지 바깥으로 넓히기. 이미지 편집, 기타 기능 → 이미지 확장
ControlNet
포즈·윤곽선·깊이를 따라 그리게 해서 구도를 고정해요.
업스케일
해상도를 키우면서 디테일을 살려요. 업스케일 탭
노드 / 워크플로
ComfyUI의 '부품'과 '연결도'예요. 이 프로그램은 자주 쓰는 연결도를 대신 만들어 주고, 직접 만든 것은 워크플로 탭에서 실행할 수 있어요.

하고 싶은 일로 찾기

글만으로 그림을 만들고 싶어요
이미지 생성 탭 → 모델을 고르고 프롬프트를 적고 [이미지 생성]. 처음이면 프로필은 '자동'으로 두세요.
마음에 든 그림을 조금만 바꿔서 또 만들고 싶어요
결과 아래 [같은 설정으로](갤러리에서는 큰 화면의 [이어서 작업 → 이미지 생성으로 보내기])를 누른 뒤 프롬프트나 시드만 바꿔요. 시드를 그대로 두면 같은 구도로 나와요.
사진 속 옷·머리색·표정만 바꾸고 싶어요
이미지 편집 → 사진을 올리고 [선택 도구]로 바꿀 곳을 클릭 → 원하는 변화를 적고 [편집 실행]. 말로만 바꾸려면 'Qwen-Image 2.1'을 쓰세요.
사진을 더 크고 선명하게 만들고 싶어요
업스케일 → 빠른 업스케일. 더 자세한 질감이 필요하면 '디테일 재생성'(실사는 변화 강도 0.2 안팎).
사진의 배경만 지우고 싶어요
이미지 편집 → [배경] → [선택 반전] → [선택만 남겨 투명 PNG 저장].
그림의 바깥을 더 넓히고 싶어요
기타 기능 → 이미지 확장. 세로 사진을 가로로 만들 때 좋아요.
어떤 설정이 좋은지 비교해 보고 싶어요
기타 기능 → 설정 비교표. 같은 시드로 CFG·단계 수만 바꿔 한 장에 모아 줘요.
인터넷에서 받은 ComfyUI 워크플로를 돌려 보고 싶어요
워크플로 탭 → [파일 열기]에 JSON이나 PNG를 올려요. 없는 노드가 있으면 알려 줘요.
새 모델·LoRA 파일을 폴더에 직접 넣었어요
왼쪽 아래 [↻ 모델 목록 새로고침]을 누르면 바로 목록에 나와요.
그림을 영상으로 움직이고 싶어요
영상 만들기 탭 → 시작 이미지를 고르고 어떻게 움직일지 적어요. 이미지 결과 아래 [영상으로] 버튼을 눌러도 돼요. 영상 한 편에 몇 분 걸려요.
만든 영상에 목소리나 음악, 자막을 넣고 싶어요
왼쪽 도구 → 영상 소리·자막. 영상과 소리(음성 만들기·음악 만들기 결과, 또는 내 파일)를 고르고 자막을 적으면 새 영상으로 합쳐 줘요. 음성을 고르면 그때 쓴 글이 자막 칸에 자동으로 들어가요. 영상 결과 아래 [소리·자막 넣기], 음성·음악 결과 아래 [영상에 넣기], 갤러리 영상의 ♪ 버튼으로도 열 수 있어요. 처음 한 번은 ffmpeg 부품 설치가 필요해요.
예전에 만든 그림을 찾고 싶어요
기록 갤러리 탭 → 프롬프트나 종류로 검색하고, ★로 즐겨찾기를 해 둬요. 마음에 드는 건 ↻로 같은 설정으로 다시 만들 수 있어요.
좋아하는 프롬프트를 저장해 두고 싶어요
프롬프트 탭 → 보관함. 생성·편집·영상 화면의 [📚 보관함에서 넣기]로 불러와요. 후보를 무작위로 바꿔 넣는 와일드카드도 여기서 만들어요.
마음에 든 사진과 비슷하게 만들고 싶어요
프롬프트 탭 → [이미지에서 프롬프트 뽑기]. 사진을 올리면 설명(프롬프트)을 만들어 줘요. 이미지를 보는 대화 모델(Qwen2.5-VL)이 필요해요.
GPU가 얼마나 쓰이는지 보고 싶어요
왼쪽 위 버전 아래에 VRAM·사용률·온도·전력이 막대로 보여요. 막대가 주황·빨강이면 여유가 거의 없는 거예요.
설치 폴더를 다른 곳으로 옮기고 싶어요
설정 탭 → [프로그램 관리] → 새 위치를 적고 [확인] → [옮기기 시작]. 폴더가 한 겹 더 들어가 있다면 [바깥 폴더로 한 단계 올리기]를 써요. 같은 드라이브에서는 몇 초면 끝나요.
화면이 멈췄거나 설정을 바꾼 뒤 적용하고 싶어요
왼쪽 아래 [⟳ 프로그램 다시 시작]을 눌러요. 스튜디오와 엔진이 다시 켜지고 화면이 자동으로 새로고침돼요.
디스크가 가득 찼어요
설치와 모델 탭 → [저장 공간 점검]에서 큰 파일과 임시 파일을 찾아 정리해요.

ComfyUI 기능을 여기서 쓸 수 있나요?

지원은 만든 쪽에서 동작을 확인한 기능이에요. 미검증은 기능은 들어 있지만 실제 PC(여러 GPU·환경)에서 확인하지 못한 기능이에요. 안 되면 [설정 → 문제 해결]의 진단 파일이나 [설치와 모델 → 내 PC 점검]으로 원인을 찾아볼 수 있어요.

일괄 처리

폴더 안의 사진(또는 고른 여러 장)을 한꺼번에 처리해요. 원본은 그대로 두고, 결과는 새 파일로 결과 폴더의 일괄 폴더에 저장돼요.

1. 처리할 사진

여기에 사진을 끌어다 놓거나 눌러서 고르세요

2. 어떻게 처리할까요?

1보다 작게 적으면 줄여요(0.5 = 절반, 모델 없이 처리). 결과가 8192px를 넘는 사진은 건너뛰고 이유를 알려 드려요.

ComfyUI에서 만든(또는 Civitai 같은 곳에서 받은) 워크플로를 그대로 실행해요. 워크플로 JSON(Save 한 것도, Save (API Format)도 모두 돼요)을 붙여 넣거나 [파일 열기]로 JSON 또는 ComfyUI로 만든 PNG 이미지를 여세요. 열면 프롬프트·이미지·시드·크기만 골라서 바꿀 수 있게 정리해 줘요.

LoRA · 모델 정보

설치된 LoRA와 모델이 어느 계열용인지, 파일 안에 적힌 트리거 단어·자주 쓰인 태그가 무엇인지 보여 줘요. LoRA 파일 옆에 같은 이름의 그림 파일(예: 이름.preview.png)이 있으면 미리보기로 써요. 이미지 생성·편집 화면에서 LoRA를 고르면 같은 정보가 칸 아래에 나오고, 단어를 누르면 프롬프트에 들어가요.

내 PC 점검

기능마다 필요한 확장·파이썬 부품·모델이 갖춰졌는지 한 번에 보여 줘요. 빠진 것은 옆의 버튼으로 바로 고칠 수 있어요. 아무것도 지우거나 바꾸지 않고, 눌러야만 설치해요.

설치한 확장·부품

기능을 쓰려고 따로 받은 ComfyUI 확장, 확장이 내려받은 모델 폴더, 파이썬 부품을 하나씩 지울 수 있어요. 지우면 그 확장을 쓰는 기능은 다시 설치하기 전까지 안 돼요. 자동으로 지우지 않고, 누를 때마다 확인을 한 번 더 물어봐요. (AI 음성 모델은 [음성 만들기] 탭에서 지워요.)

저장 공간

어디에서 용량을 쓰는지 폴더별로 보여 주고, 지워도 안전한 임시 파일만 골라서 정리해 줘요. 모델과 결과 이미지는 자동으로 지우지 않아요.

화면에 올려 둔 사진은 다시 켜도 그대로 불러와요.

폴더 열기

모델 파일을 직접 넣을 때 쓰세요. 파일을 넣고 이 창으로 돌아오면 목록이 자동으로 새로고침돼요.

설정

모델 설치와 폴더는 설치와 모델에 있어요. 바꾼 값은 바로 적용되고 이 컴퓨터에 기억돼요.

모양

글자·메뉴 크기글자와 왼쪽 메뉴가 같이 커지거나 작아져요. 브라우저 확대(Ctrl + 휠)와 따로 기억돼요.
글꼴화면 전체 글꼴이에요. 컴퓨터에 없는 글꼴은 기본 글꼴로 보여요.
화면 색어둡게·밝게, 또는 컴퓨터 설정을 따라가요.
강조 색버튼과 선택 표시에 쓰는 색이에요.
대화 글자 크기대화 화면의 글자만 따로 키우거나 줄여요.
움직임 줄이기버튼·메뉴·스위치·진행 막대의 전환 효과를 꺼요(원래 짧은 효과라 차이가 작아요). 로딩 표시는 느리게 돌아요.
안내 문구 줄이기각 화면의 회색 설명 글을 숨겨서 더 간결하게 보여 줘요.

시작과 목록

시작하기 탭 보이기왼쪽 메뉴 맨 위의 [시작하기](준비 상태·처음 쓰는 사람용 안내)를 보이거나 숨겨요.
시작할 때 열 화면스튜디오를 열 때 맨 처음 보이는 화면이에요.
생성 결과 그림 크기이미지 생성·편집 화면에서 결과 그림이 보이는 크기예요. 누르면 크게 볼 수 있어요.
작업 대기열 위치작업 대기열 메뉴의 위치를 바꿀 수 있어요.
왼쪽 메뉴 너비왼쪽 메뉴(사이드바)의 폭이에요.
대화 말풍선 너비대화 답변이 한 줄에 놓이는 최대 폭이에요.
알림 메시지 표시 시간화면 아래에 잠깐 뜨는 안내 문구가 머무는 시간이에요.
만들기 버튼 고정입력 칸을 내려도 [만들기] 버튼이 위에 따라와요. 끄면 제자리에 있어요.
한 줄 화면 너비설정·다운로드·설치와 모델·프롬프트·일괄 처리처럼 오른쪽 칸이 없는 화면의 최대 너비예요. 넓은 모니터에서 오른쪽이 많이 비면 넓혀 보세요.
갤러리 미리보기 크기기록 갤러리의 그림 크기예요.
갤러리 미리보기[끄기]로 두면 그림을 불러오지 않고 파일 이름·프롬프트만 보여 줘요. 그림이 아주 많아 느릴 때 쓰세요. 칸을 누르면 큰 그림으로 열려요.

프롬프트 입력

태그 자동완성프롬프트 칸에 두 글자 이상 쓰면 아래에 후보를 보여줘요.

기본 태그에 더해 내가 저장한 프롬프트, LoRA 트리거 단어, __와일드카드__도 나와요. ↓↑로 고르고 Tab이나 Enter로 넣어요. danbooru 형식 태그 목록(csv)을 tags 폴더에 넣으면 그것도 같이 써요.

단축키

Ctrl + Enter 로 만들기지금 화면의 [만들기·실행] 버튼을 눌러요 (Mac은 ⌘).
/ 키로 검색 칸 이동기록 갤러리·프롬프트 화면에서 검색 칸으로 바로 가요.
마우스 뒤로·앞으로 버튼마우스 옆면의 4번(뒤로)·5번(앞으로) 버튼으로 직전에 보던 화면으로 가요. 열린 확대 보기나 대기열이 있으면 먼저 닫아요.
화면 이동 키Alt+←/→ 뒤로·앞으로, Alt+1~9 대화·이미지 생성·이미지 편집·업스케일·갤러리·프롬프트·설치와 모델·설정·시작하기로 바로 이동, ? 이 단축키 목록 열기.
Esc열린 창(확대 보기, 대기열)을 닫아요. 항상 켜져 있어요.

작업이 끝났을 때

소리로 알려주기작업이 끝나면 짧은 알림음을 내요.
바탕화면 알림다른 창을 보는 중일 때 작업이 끝나면 알림을 띄워요. 처음 켤 때 브라우저가 허락을 물어봐요.
창을 닫을 때 경고작업이 진행 중인데 탭을 닫거나 새로고침하면 한 번 물어봐요.

웹 검색 (SearXNG)

검색 서버대화에서 '웹 검색'을 켜면 이 서버로 검색해요. SearXNG 는 내 PC 에서 도는 검색 중계 서버라 키·요금이 없어요.
확인 중…
설치·켜기Docker Desktop 이 있으면 버튼 한 번으로 SearXNG 를 받아 켜요(처음 한 번 수백 MB).
주소이미 띄워 둔 SearXNG 가 있으면 주소를 넣어요. 설정에서 JSON 결과(search > formats: json)가 켜져 있어야 해요.
본문까지 읽을 결과 수위쪽 결과 몇 개는 페이지 본문까지 읽어 답이 더 정확해져요. 늘리면 느려져요.

메모리와 속도

대화 모델을 메모리에 두는 시간마지막 대화 뒤 이 시간이 지나면 모델을 내려서 그래픽 메모리를 비워요. 길수록 다음 대답이 빠르고, 짧을수록 이미지 생성에 메모리를 더 줘요.
그래픽 메모리(VRAM) 사용 방식메모리 부족 오류가 자주 나면 '아끼기'로 바꿔요. 느려지지만 큰 모델도 돌아가요. 프로그램을 다시 시작하면 적용돼요.
다른 프로그램용으로 남겨 둘 VRAM게임·방송 프로그램 등을 같이 쓸 때 이만큼은 이미지 엔진이 쓰지 않아요. 프로그램을 다시 시작하면 적용돼요.
모델을 메모리에 붙잡아 두기끄면 작업이 끝날 때마다 모델을 RAM·VRAM 에서 내려서 메모리를 덜 써요(다음 작업 시작은 느려져요). 프로그램을 다시 시작하면 적용돼요.
대화 모델이 쓸 장치'CPU만'으로 하면 대화가 그래픽 메모리를 쓰지 않아 이미지 작업과 같이 쓸 때 메모리 부족이 줄어요(대화는 느려져요).
이미지 모델을 메모리에 두는 시간이미지 작업이 끝난 뒤 이 시간이 지나면 이미지 모델을 그래픽 메모리에서 내려요. 길수록 다음 그림이 빨리 시작하고, 짧을수록 게임 같은 다른 프로그램에 메모리를 더 줘요.
이미지 속도 옵션 (fp16 누적)ComfyUI가 지원할 때만 쓰는 안전한 속도 옵션이에요. 문제가 생기면 끄세요. 프로그램을 다시 시작해야 적용돼요.
미리보기 캐시 최대 용량갤러리에서 처음 볼 때 작은 미리보기를 만들어 둬서 다음부터 빨리 떠요. 이 용량을 넘으면 오래 안 본 미리보기부터 지우고, 사진을 지우면 그 미리보기도 같이 지워요. 원래 사진은 건드리지 않아요.

설정 백업 · 복원

프롬프트 보관함, 와일드카드, 즐겨찾기, 내가 적은 LoRA 정보(트리거 단어·종류), 화면별 프리셋을 파일 하나로 저장하거나 되살려요. 다른 PC로 옮기거나 재설치 전에 쓰면 좋아요. 모델·결과 이미지는 용량이 커서 포함하지 않아요.

어느 쪽이든 아무것도 지우지 않아요. 바꾸기 전 파일은 backups 폴더에 복사해 둬요.

문제가 생겼을 때

안 되는 기능이 있을 때 원인을 찾는 데 필요한 정보(버전, 그래픽카드, 설치된 확장·모델 파일 이름, 최근 오류, 로그 끝부분)를 zip 하나로 묶어요. 프롬프트·만든 이미지·API 키는 들어가지 않아요. 보내기 전에 안의 txt 파일을 열어 확인할 수 있어요.

업데이트 파일 적용

받은 업데이트 파일(LocalAI-Studio-update-….bat)을 아래에 끌어다 놓거나 눌러서 고르세요. 먼저 바뀔 파일을 보여 드리고, 확인하면 적용해요. 적용하기 전에 이전 파일을 backup 폴더에 복사해 두고, 문제가 생기면 rollback.bat 으로 되돌릴 수 있어요. 엔진·모델·결과물·설정은 건드리지 않아요. 믿을 수 있는 곳에서 받은 파일만 쓰세요.
